# Strict Rule: No Emojis in UI or Messages

## Directive
- **DO NOT USE EMOJIS** (e.g. 🟢, 💬, 📤, 🎉, ⏳, ✅, 📜, 🏭, 📝, 💵, ⚙️, 🎨) anywhere in the application UI, buttons, text labels, or system response messages.
- Always use **Lucide React icons** (`lucide-react`) for UI elements and clear markdown text for assistant responses.
